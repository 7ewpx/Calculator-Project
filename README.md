# Python Calculator
## Screenshot

![Calculator Screenshot](calculator.png)
مشروع آلة حاسبة بسيطة بواجهة رسومية باستخدام Python و Tkinter.

## المميزات
- الجمع والطرح والضرب والقسمة.
- الأقواس والكسور العشرية.
- النسبة المئوية والأسس.
- زر مسح الكل والحذف.
- دعم لوحة المفاتيح.
- التحقق من العمليات الحسابية قبل تنفيذها.

## المتطلبات
- Python 3
- مكتبة Tkinter (تأتي غالباً مع تثبيت Python)

## التشغيل
1. حمّل ملفات المشروع.
2. افتح الطرفية داخل مجلد المشروع.
3. شغّل الأمر:

```bash
python calculator.py
```

على بعض الأجهزة قد تحتاج إلى:

```bash
python3 calculator.py
```

## ملاحظات
هذا مشروع تعليمي بسيط، ويستخدم `ast` للسماح بالعمليات الحسابية المحددة فقط بدلاً من تنفيذ `eval` مباشرة.
